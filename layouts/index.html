A first-principles ML journey

Building understanding from the ground up

Synaptic Radio is a ground-up exploration of machine learning and foundation-model engineering. I start with the assumptions beneath an idea, rebuild the mechanism, and test whether the explanation survives contact with code and real systems.

This is both a record of what I have learned through my own work and a working notebook for what I am still learning. The purpose is to make the journey visible: the reasoning, experiments, wrong turns, and engineering choices that turn an abstract concept into practical understanding.
